# Format (one directive per line, tokens separated by a TAB character, lines starting
# with # are comments):
#   include      <glob>
#   skip-file    <glob>                          <why it is excluded>

# 形式 (1行1指示・トークン区切りはタブ文字・# 始まりはコメント):
#   include      <glob>

# include is the only authority; only the places listed here are scanned.
# skip-region enters a region every time the start line matches, and closes the region
# at the next line that matches the end line (both ends are excluded). The same shape of
# region may appear more than once in a single file.
# include が唯一の権威。ここに挙げた場所だけを走査する。
# skip-region は開始行にマッチするたびに区間へ入り、次に終了行にマッチした行で

# Target packages: the three packages falcon / chewie / falcon-docker-beta, plus the
#   *.md files directly under the repository root.

#   screen of the person who receives the package".
# 対象の配布物: falcon / chewie / falcon-docker-beta の3つ + リポジトリ直下の *.md

Deployment Guide About This Document
About This Document
Cynovela is a completely unofficial learning tool, built so that one individual can understand the concepts of an AI platform tool by working on them hands-on. It is not a commercial product or an official implementation. Everything is implemented originally, on an OSS stack of FastAPI / SQLite / ChromaDB / BGE-M3 / a local LLM. It does not represent the official view of any company or product in any way.

This document collects the procedure for deploying Cynovela into a local environment.

Deployment Guide 5. Connecting to LM Studio

The default LLM provider of Cynovela is LM Studio. It can also connect to any service that has a /v1-compatible API.

python server.py --demo --lmstudio-url http://localhost:1234

An example of the setting in cynovela.yaml:

llm:
  provider: lmstudio
  base_url: http://localhost:1234
  api_key: ""
  model: ""
  max_concurrent: 3
  timeout_seconds: 120
Important: Do not pass max_tokens to the LM Studio API. It causes the token budget for thinking to run out on Reasoning models.
Cynovela Unofficial / personal learning / Alpha GA
Deployment Guide 5. Ollama / OpenRouter / vLLM / Mock (2/2)

Setting llm.provider to openai_compat lets you switch to an OpenAI-compatible endpoint other than LM Studio (vLLM, the /v1-compatible gateway of Ollama, and so on).

llm:
  provider: openai_compat
  base_url: http://localhost:11434/v1   # 例: Ollama
  model: llama3

The Reranker is a separate path; setting reranker.provider to ollama lets you use Ollama as the Reranker.

Mock LLM

The --mock option that used to exist (which replaced LLM calls with a mock) has been removed. Specifying it now stops with an error.

デプロイメントガイド 5. LM Studio との接続

Cynovela の既定 LLM プロバイダーは LM Studio です。/v1 互換 API を持つ任意のサービスにも接続できます。

python server.py --demo --lmstudio-url http://localhost:1234

cynovela.yaml での設定例:

llm:
  provider: lmstudio
  base_url: http://localhost:1234
  api_key: ""
  model: ""
  max_concurrent: 3
  timeout_seconds: 120
重要: LM Studio API には max_tokens を渡さないでください。Reasoning モデルで思考用トークン予算が枯渇する原因となります。

デプロイメントガイド 5. Ollama / OpenRouter / vLLM / モック (2/2)

llm.provider を openai_compat にすると、LM Studio 以外の OpenAI 互換エンドポイント（vLLM、Ollama の /v1 互換ゲートウェイなど）に切り替えられます。

llm:
  provider: openai_compat
  base_url: http://localhost:11434/v1   # 例: Ollama
  model: llama3

Reranker は別系統で、reranker.provider を ollama に設定すると Ollama を Reranker として利用できます。

モック LLM

以前あった --mock（LLM 呼び出しをモックに置き換える指定）は撤去済みです。いま指定するとエラーで止まります。

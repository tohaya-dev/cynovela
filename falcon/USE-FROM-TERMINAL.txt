=== English ===

Cynovela entry point — this one file is all the recipient has to type.
This form runs in a container.

● When you add nothing
  ./launch.sh                     It starts by having you answer the questions with a number.
                                  (what to have it read / which configuration to run with)

● Deciding up front instead of answering with numbers
  ./launch.sh --demo              Starts with the bundled dummy documents loaded.
  ./launch.sh --add               Shows a folder chooser and adds the folder to be read.
  ./launch.sh --list              Lists the folders you have added so far.
  ./launch.sh --remove <名前>     Removes a folder you added (the name is the one shown by --list).
                                  ※ You can also view and remove them on the screen, at 設定 → 取り込み元.
                                  ※ Because this form runs in a container, what you added becomes
                                    readable only after you type ./launch.sh again.

● Install / check
  ./launch.sh --setup             Prepares what can be prepared inside this package.
  ./launch.sh --check             Does not start; only checks the conditions for running
                                  and writes them to a single file.

● Other
  ./launch.sh --port <番号>       Changes the port it opens on (default 8801).
                                  When you add nothing, it picks a free number by itself.
  ./launch.sh --local-only        Narrows what it opens on to your own machine only.
  ./launch.sh --engine <値>       Specifies the executable to use for the container (a name or an absolute path).
                                  The setting with the same meaning: engine: under container: in cynovela.yaml
  ./launch.sh --engine-command <値>
                                  Replaces the start command itself (empty by default).
                                  The setting with the same meaning: engine_command: under container: in cynovela.yaml
  bash stop.sh                    Stops it (does not delete it).

● Where it opens and how to log in
  Where it opens : http://127.0.0.1:8801   (the number you gave, when you used --port)
  How to log in  : administrator cynovela / viewer demo
                   The first passwords are in the "ログイン" (Login) section of the bundled STARTUP.md.
                   The administrator is asked to change the password on the first login.
                   Until that is finished, administrative operations do not go through.

This form has no python to choose (the python that runs the app is inside the container,
and neither the host's python nor conda is used).

Options for testing and development can be seen with ./launch.sh --help-all.

=== 日本語 ===

Cynovela 入口 — 受け取り手が叩くのはこの1本だけです。
この系統はコンテナで動きます。

● 何も付けないとき
  ./launch.sh                     聞かれたことに番号で答えるだけで起動します。
                                  (何を読ませるか / どの構成で動かすか)

● 番号で答えずに、はじめから決めて起動する
  ./launch.sh --demo              同梱のダミー資料が載った状態で起動します。
  ./launch.sh --add               読み込むフォルダを選ぶ画面を出して足します。
  ./launch.sh --list              いま足してあるフォルダを一覧で出します。
  ./launch.sh --remove <名前>     足したフォルダを外します (名前は --list に出るもの)。
                                  ※ 画面でも 設定 → 取り込み元 から見る・外せます。
                                  ※ この系統はコンテナで動くため、足したものが読めるように
                                    なるのは、もう一度 ./launch.sh を叩いたあとです。

● 入れる / 点検する
  ./launch.sh --setup             この配布物の中で用意できるものを用意します。
  ./launch.sh --check             起動せず、動く条件だけを調べて1本のファイルへ書きます。

● そのほか
  ./launch.sh --port <番号>       開く番号を変えます (既定 8801)。
                                  何も付けないときは、空いている番号を自分で選びます。
  ./launch.sh --local-only        開く先を自分のマシンの中だけに絞ります。
  ./launch.sh --engine <値>       コンテナに使う実行ファイルを指定します (名前または絶対パス)。
                                  同じ意味の設定: cynovela.yaml の container: の engine:
  ./launch.sh --engine-command <値>
                                  起動に使うコマンドそのものを差し替えます (既定は空)。
                                  同じ意味の設定: cynovela.yaml の container: の engine_command:
  bash stop.sh                    止めます (消しません)。

● 開く場所と入り方
  開く場所 : http://127.0.0.1:8801   (--port を使ったときはその番号)
  入り方   : 管理者 cynovela / 閲覧者 demo
             最初のパスワードは同梱の STARTUP.md の「ログイン」の節にあります。
             管理者は最初に入ったときにパスワードの変更を求められます。
             変え終わるまで管理の操作は通りません。

この系統には選ぶ python がありません (本体を動かす python はコンテナの中にあり、
ホスト側の python も conda も使いません)。

試験・開発のための指定は ./launch.sh --help-all で見られます。

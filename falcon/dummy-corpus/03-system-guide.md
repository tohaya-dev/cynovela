# 社内システム「アオゾラ在庫台帳」利用手順書

本書は、アオゾラ商事株式会社の社内在庫管理システム「アオゾラ在庫台帳」の基本操作をまとめた手順書です。対象は本社および大阪支社・福岡支社の全利用者です。

## 1. システムの概要

「アオゾラ在庫台帳」は、当社が取り扱う生活雑貨(キッチン用品・バス・トイレタリー・収納用品・季節雑貨)の在庫を一元管理する社内システムです。2020年の導入以降、入庫・出庫・棚卸し・月次締めの各業務を本システム上で行っています。

利用には利用者アカウントが必要です。アカウントの発行・停止は情報システム担当が行います。

**重要: 在庫台帳の月次締め処理は毎月25日に実施する。** これは在庫業務上の締め日であり、経費精算の締め(月末締め)とは異なるので注意すること。

## 2. ログイン手順

1. 社内ネットワークに接続した端末で、ブラウザを起動する。
2. ブックマークまたは社内ポータルのリンクから「アオゾラ在庫台帳」のログイン画面を開く。
3. 利用者IDとパスワードを入力し、「ログイン」を押す。
4. 初回ログイン時は、パスワードの変更画面が表示される。画面の案内に従い、新しいパスワードを設定する。
5. ログインに5回連続で失敗するとアカウントがロックされる。ロックされた場合は、情報システム担当に解除を依頼する。

### ログインできないときの確認事項

- 社内ネットワークに接続しているか(社外からは接続できません)
- 利用者IDに誤りがないか
- キーボードの大文字固定が有効になっていないか

## 3. 入庫登録の手順

入庫登録は、仕入先から商品が到着した当日中に行うことを原則とします。

1. メニューから「入庫」→「入庫登録」を選ぶ。
2. 発注番号を入力し、「呼出」を押す。該当する発注情報が画面に表示される。
3. 納品書と現物を照合し、実際に受け入れた数量を「入庫数」欄に入力する。
4. 数量が発注数と異なる場合は、「差異区分」から理由(欠品・破損・過納)を選び、備考欄に状況を記入する。
5. 商品を保管する棚番号を「棚番」欄に入力する。
6. 内容を確認し、「登録」を押す。登録が完了すると入庫伝票番号が表示される。
7. 入庫伝票番号を納品書に転記し、納品書は所定のファイルに綴じて保管する。

### 入庫登録の注意事項

- 破損品を受け入れた場合は、登録後すみやかに仕入担当へ連絡する。
- 季節雑貨は専用の棚番(Sで始まる棚)に保管し、通常棚と混在させない。
- 当日中に登録できない事情がある場合は、所属長に報告のうえ翌営業日の午前中に登録する。

## 4. 棚卸しの手順

棚卸しは、毎月の月次締めに先立って実施する実地確認作業です。各拠点の在庫担当が行います。

1. メニューから「棚卸し」→「棚卸表出力」を選び、担当する棚範囲の棚卸表を印刷する。
2. 棚卸表に従い、棚ごとに現物の数量を数え、実数を記入する。
3. メニューから「棚卸し」→「実数入力」を選び、棚卸表に記入した実数をシステムに入力する。
4. システムが帳簿数量と実数の差異を自動計算し、差異一覧が表示される。
5. 差異がある品目については、現物を再確認する。数え間違いであれば実数を修正する。
6. 再確認しても差異が解消しない場合は、「差異報告」画面から報告を登録し、所属長の確認を受ける。
7. すべての棚の入力と差異確認が終わったら、「棚卸し完了」を押す。

### 棚卸しの注意事項

- 棚卸し作業中は、対象棚への入庫・出庫作業を停止する。
- 棚卸表は表計算ソフトの形式でも出力できるが、正式な記録はシステム上の登録内容とする。
- 差異報告を登録せずに「棚卸し完了」を押すことはできない。

## 5. 月次締めの手順

月次締めは、当月の在庫データを確定させる処理です。**在庫台帳の月次締め処理は毎月25日に実施する**(25日が休日の場合は直前の営業日)。締め処理は各拠点の締め担当者のみが実行できます。

1. 締め日の前営業日までに、当月分の入庫・出庫登録がすべて完了していることを各担当に確認する。
2. 棚卸しが「棚卸し完了」の状態になっていることを確認する。
3. メニューから「月次」→「月次締め」を選ぶ。
4. 画面に表示される締め対象月を確認する。
5. 「締め前チェック」を押す。未登録の伝票や未完了の棚卸しがある場合はエラー一覧が表示されるので、該当担当に修正を依頼し、修正後に再度チェックを行う。
6. チェックがすべて通ったら、「月次締め実行」を押す。
7. 処理が完了すると月次確定レポートが作成される。締め担当者はレポートを保存し、所属長に提出する。

### 月次締めの注意事項

- 締め処理の実行後は、当月分のデータを修正できない。修正が必要な場合は、翌月に修正伝票で対応する。
- 締め処理は拠点ごとに実行するが、実施日は全拠点とも毎月25日で統一されている。
- 経費精算の締め(月末締め・翌月15日払い)は経理の手続であり、本システムの月次締めとは無関係である。混同しないこと。

## 6. 困ったときは

- 操作方法が不明な場合: 本書と社内ポータルの「よくある質問」を確認する。
- 画面にエラーが表示された場合: エラー内容を控え、情報システム担当に連絡する。
- 締め処理に関する相談: 各拠点の締め担当者または管理本部に連絡する。

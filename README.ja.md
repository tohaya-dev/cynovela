# Cynovela
企業の AI データパイプラインの「縮小図」です。資料を取り込み、個人情報を伏せ、
公開し、出典つきの答えを返す。そして役割ごとに見えるものを分ける。ここまでを
手元の機材だけで動かします。
個人利用・社内の限られたお披露目・学び直しのための道具です。売り物ではなく、
実務でそのまま使うことを想定していません。
名前は造語です。cynosure（導きの星）と Vela（帆座）から。読みは「シノヴェラ」。
## 要るもの
- Apple silicon の macOS。
- **falcon**（入れ物の中で動く形）＝`Podman` を既定とします。
- **chewie**（Mac の上で直に動く形）＝`conda` を既定とし、無ければ `venv` も
  選べます。
- `Docker` その他も選べますが、当方では確認していません。利用者が自分で調整する
  必要があります。
- モデルを同梱しない形を選んだ場合、初回にインターネットが要ります。
## 配る形
| 形 | 動き方 | モデルの同梱 |
|---|---|---|
| falcon 全部入り | 入れ物 | する |
| falcon 軽量版 | 入れ物 | しない |
| chewie 全部入り | Mac の上で直に | する |
| chewie 軽量版 | Mac の上で直に | しない |
全部入りは大きいため、片に割ってあります。組み立て方と確かめ方は、片と同じ場所に
置く `HOW-TO-ASSEMBLE.md` と `SHA256SUMS` に書いてあります。リリースがまだ
並んでいない場合、配布物はこの時点では公開されていません。
## 動かし方
1. 選んだ形をダウンロードして組み立てます。
2. 同梱の起動用のファイルから起動します。
3. 表示された URL を開き、`STARTUP.md` に書かれたアカウントでログインします。
   管理者は最初のログインでパスワードの変更を求められます。
## できないこと
- **伏字は完全ではありません。** 外へ出す前に型に合わせた置き換えを行いますが、
  取りこぼしは起こります。分かっているものだけでも、ふりがなの氏名、住所の番地
  から先、固定電話の一部の市外局番があります。
- 学びと試しのための道具です。本物の機密資料を通さないでください。出てきた答えを
  そのまま正しいものとして扱わないでください。
- `Podman` 以外の入れ物での動きは、当方では確かめていません。

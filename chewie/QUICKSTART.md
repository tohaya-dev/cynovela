## 0. 用意するもの

| もの | 要件 |
|---|---|
| Mac | Apple シリコン（M1 以降）。Intel の Mac・Windows・Linux では確認していません |
| ディスクの空き | 展開後およそ 3.1 GB ＋ AIモデル 4.84 GB |
| メモリ | 8 GB 以上を推奨 |
| 答えを作るモデル | 次のいずれか1つ。**これが無いと、質問しても答えが返りません**<br>・LM Studio（この Mac の中で動かす）<br>・Ollama（この Mac の中で動かす）<br>・OpenAI と同じ形の口を持つサービス（利用の鍵が要ります） |

Python も conda も要りません。この Mac には何も入りません。消すときはフォルダごと
削除するだけです。

**会社から貸与された Mac をお使いの方へ。** リリースのページに置いてある
`check-managed-mac.command` を先に落として、ダブルクリックしてください。この Mac が
動かせる状態かどうかだけを調べます。設定は何も変えず、管理者のパスワードも要りません。

## 1. 落とす

リリースのページから、次の**5つ**を**同じフォルダ**に落とします。

```
cynovela-chewie-package-1.2.0.tar.gz          本体
cynovela-chewie-models-1.2.0.tar.gz.part00    AIモデル（1/3）
cynovela-chewie-models-1.2.0.tar.gz.part01    AIモデル（2/3）
cynovela-chewie-models-1.2.0.tar.gz.part02    AIモデル（3/3）
SHA256SUMS                                    壊れていないか確かめるための一覧
```

**この3つは、資料を探すために使うモデルです**（文章を数字の並びに変える埋め込みモデルと、検索結果を並べ替えるモデル）。**答えを作る LLM は入っていません。**5節で別に用意します。3つに分かれているのは、1つのファイルが大きすぎて置けないためです。

次の手順でつなげます。

## 2. つなげる・確かめる・展開する

ターミナルを開きます（`アプリケーション` → `ユーティリティ` → `ターミナル`）。

**2-1. 落としたフォルダへ移動する**

```
cd ~/Downloads
```

**2-2. AIモデルの3つをつなげて、1つにする**

```
cat cynovela-chewie-models-1.2.0.tar.gz.part00 cynovela-chewie-models-1.2.0.tar.gz.part01 cynovela-chewie-models-1.2.0.tar.gz.part02 > cynovela-chewie-models-1.2.0.tar.gz
```

**2-3. 壊れていないか確かめる**

```
shasum -a 256 --ignore-missing -c SHA256SUMS
```

出てくる行が全部 `OK` なら次へ進みます。`FAILED` が出たら、その部品を落とし直して
2-2 からやり直してください。**確かめずに先へ進まないでください。**

**2-4. 本体を展開する**

```
tar -xzf cynovela-chewie-package-1.2.0.tar.gz
```

`chewie` というフォルダができます。

**2-5. AIモデルを、そのフォルダの中に展開する**

```
cd chewie
tar -xzf ../cynovela-chewie-models-1.2.0.tar.gz
```

`store/models/` ができます。**この場所でないと見つけられません。**

**フォルダを置く場所について**

- **クラウド同期のフォルダの中には置かないでください**（iCloud Drive・Dropbox・
  OneDrive・Google Drive）。ファイルが実行できない形に置き換えられます。
  `~/Downloads` かホームフォルダが安全です
- あとから別の場所へ移せます。読み込んだ資料も設定も一緒に移ります

## 3. 起動する

展開してできた `chewie` フォルダを Finder で開きます。

### サンプルの資料で試す（おすすめ）

`Cynovela-demo.command` を**ダブルクリック**します。

- ターミナルの窓が開いて、起動の様子が流れます
- **初回だけ、サンプル資料21件の読み込みに40秒ほどかかります**
- 2回目からは読み込み直しません

### 何も入っていない状態で始める

`Cynovela-start.command` を**ダブルクリック**します。

### ターミナルから起動する

```
./launch.sh --demo      サンプル資料あり
./launch.sh             何も入っていない状態
```

### 開く場所（アドレス）について

起動したターミナルの画面に、次のように出ます。

```
開く場所: http://localhost:8765
```

🔴 **この番号は変わることがあります。** いつもの番号が別のものに使われていた場合は、
空いている番号が自動で選ばれ、こう出ます。

```
※ いつもの番号 (8765) は別のものが使っていました。8766 を使います。
開く場所: http://localhost:8766
```

**画面に出ている番号を見てください。**

番号を自分で決めたいときは、ターミナルから起動します。

```
./launch.sh --demo --port 9000
```

**ダブルクリックでは番号を指定できません。**

## 4. ログインする

ブラウザが自動で開きます。開かないときは、3節で画面に出た場所を自分で開いてください。

**4-1. 名前を入れる**

| 役割 | 名前 |
|---|---|
| 管理者（全部できる） | `cynovela` |
| 閲覧者（見るだけ） | `demo` |

**4-2. 最初のパスワード**

**最初のログイン。パスワードを探す必要はありません。**
**はじめて起動したとき、ターミナルの画面に1回だけ出ます。**

    ────────────────────────────────────────────────
      First login / はじめてのログイン
        Open / ひらく          : http://localhost:8765
        User name / ユーザー名 : cynovela
        Password / パスワード  : （ここに出ます）
      最初のログインで変更を求められます。
      この表示が出るのは初回だけです。
    ────────────────────────────────────────────────

- **出るのは初回だけです。**2回目からは出ません。
- **管理者は `cynovela`、閲覧者は `demo` です。**
- **管理者は最初のログインでパスワードの変更を求められます。**閲覧者には求めません。
- **別便で届くものはありません。**
- **この画面を見逃した場合**は、展開したフォルダの `cynovela.yaml`
  （`launch.sh` と同じ場所）の `auth.admin_initial_password` に同じ値が書いてあります
  （閲覧者のぶんは `auth.viewer_initial_password`）。

| 役割 | 利用者名 | 最初のパスワード |
|---|---|---|
| **管理者**（全部できる） | `cynovela` | **はじめて起動したとき、ターミナルの画面に1回だけ出ます** |
| **閲覧者**（見るだけ） | `demo` | 展開したフォルダの `cynovela.yaml`（`auth.viewer_initial_password`）にあります |

**管理者の値を見逃した場合は、**同じ `cynovela.yaml`（`launch.sh` と同じ場所）の
`auth:` にもあります。

**4-3. パスワードを変える**

管理者で入ると、すぐに変更を求められます。**変えるまで管理の操作はできません。**
閲覧者は求められません。

## 5. 答えを作るモデルにつなぐ

🔴 **ここを飛ばすと、質問しても答えが返りません。必ず先にやってください。**

### 5-1. つなぐ先を用意する

使うものに応じて、先に用意します。

| 使うもの | 用意すること |
|---|---|
| **LM Studio** | 起動して、`Developer` のタブでサーバーを `Start` にし、チャット用のモデルを1つ読み込む |
| **Ollama** | 起動して、モデルを1つ用意する |
| **OpenAI と同じ形の口を持つサービス** | 利用の鍵（API キー）を手元に用意する |

### 5-2. 設定の画面を開く

左のメニューから `Settings` を開きます。`🤖 AI / LLM 設定` の中に
`🤖 LLM プロバイダー` があります。

### 5-3. つなぐ先を選んで、入れる

`プロバイダー` の欄から選びます。

| 選ぶもの | `Base URL` | 鍵 |
|---|---|---|
| LM Studio | `http://localhost:1234`（既定のまま） | 要りません |
| Ollama | Ollama の場所 | 要りません |
| OpenAI 互換 | そのサービスの場所 | **API キーを入れます** |

`Model` の欄は、次の手順で一覧から選びます。

### 5-4. 🔴 押す順番（この順でないと保存されません）

**1つずつ、この順で押してください。**

```
① 🔌 接続テスト           つながることを確かめる
② 📋 モデル一覧を取得      使えるモデルの一覧を出す
③ 一覧からモデルを選ぶ
④ 💾 LLM 設定をまとめて適用   ★これを押して初めて保存されます
```

🔴 **④ を押すまで、設定は保存されていません。**

途中にある `保存` のボタンや、`✅ 適用完了` `✅ 適用しました` `✅ 保存しました`
といった表示は、**それぞれ別の項目のものです。** ④ の代わりにはなりません。

🔴 **あとからモデルを変えるときも、① から ④ を同じ順でやり直してください。**
一覧を取り直さずにモデルの名前だけ書き換えても、うまく切り替わらないことがあります。

## 7. 自分のパソコンに保存してあるファイルを読み込ませる

🔴 **フォルダを足しただけでは、まだ質問できません。4つの手順が要ります。**

### 7-1. 読み込めるファイルの種類

| 種類 | 拡張子 |
|---|---|
| 文書 | `.txt` `.md` `.csv` `.pdf` `.docx` |
| 表計算・プレゼン | `.xlsx` `.xls` `.pptx` |
| ウェブ・メール | `.html` `.htm` `.eml` |
| まとめたもの | `.zip`（中の `.zip` は開きません） |
| 画像 | `.jpg` `.jpeg` `.png` `.heic` `.webp` `.gif` |

🔴 **画像ファイルは読めません（現在開発中）。**写真やスクリーンショットの中身で探すことはできません。

**読み込めないもの**: `.doc` `.ppt` `.rtf` `.odt` `.ods` `.odp` `.json` `.xml`
`.yaml` `.msg` `.epub` `.mp3` `.mp4` `.tif` `.bmp` `.svg` `.7z` `.rar`

### 7-2. 手順1 — 読み込む元のフォルダを足す

`Cynovela-add-folder.command` を**ダブルクリック**します。フォルダを選ぶ画面が
出るので、読ませたいファイルが入っているフォルダを選びます。

ターミナルからなら次のとおりです。

```
./launch.sh --add       足す
./launch.sh --list      いま足してあるものを見る
```

**この時点では、場所を登録しただけです。まだ中身は読んでいません。**

- 🔴 **足せるのはフォルダ単位です。ファイルを1つだけ指定することはできません。**読ませたいファイルが入っているフォルダごと足してください。
- 🔴 **何も足していない状態では、同梱のサンプル資料だけが対象です。**

### 7-3. 手順2 — 取り込む

画面の読み込み元の一覧から、足したフォルダの取り込みを始めます。

**どれくらい時間がかかるか（実測）**

| 入れたもの | かかった時間 |
|---|---|
| ワープロ文書やテキストを20件ほど | **1〜2分** |
| ページ数の多い技術資料の PDF を1本 | **約6分** |
| すでに読み込んだところへ PDF を1本足す | **1分ほど** |
| 数千ページの大きな技術資料 | **数十分** |

Apple シリコンの Mac で測った値です。同じページ数でも、図や写真が多い資料は
文字中心の資料より速く終わります。読み取る文章の量が少ないためです。

一度読み込んだあとに資料を足したときは、足した分だけを処理するので短時間で終わります。

**進み具合は画面に出ます。** `マスキング処理中` のあと `Embedding生成中` に変わり、
何件目まで進んだかが出ます。

🔴 **時間がかかっても、画面を閉じてかまいません。** 取り込みは裏で動き続けます。
ブラウザを閉じても、別の画面へ移っても止まりません。あとで戻れば、終わっているか、
どこまで進んだかが見られます。

ただし、**アプリ自体を止めたり、Mac を再起動したりすると、取り込みは中断されます。**
次に起動したとき、そのまとまりは「中断」の状態で出てきます。もう一度公開してください。

### 7-4. 手順3 — ワークスペースと結び付ける

左のメニューから `Collections` を開き、`＋ Collection作成` を押します。
**どのワークスペースに、どの読み込み元を入れるか**をここで決めます。

ワークスペースが無ければ `新しいワークスペースを作成` から作ります。

### 7-5. 手順4 — 公開する

作ったまとまりを**公開**します。ここで個人情報を伏せる処理が走ります。

🔴 **公開して初めて、`RAG Chat` の対象になります。** 取り込んだだけでは質問に
使われません。

公開が終わると、読み込んだ件数・切り分けた数・個人情報を伏せた件数・かかった時間が
まとめて出ます。

### 7-6. 質問する

`RAG Chat` を開き、`🏢 Workspace` で作ったワークスペースを選んで質問します。

## 8. 止める・次から起動する・消す

**止める**

`Cynovela-stop.command` を**ダブルクリック**します。ターミナルからは `bash stop.sh` です。
読み込んだ資料と設定はそのまま残ります。

**次から起動する**

`Cynovela-start.command`（または `Cynovela-demo.command`）を**ダブルクリック**する
だけです。作り直しは起きません。

**消す**

展開したフォルダを削除します。この Mac には何も残りません。

## 9. ダブルクリックの入口と、ターミナルの指定

### 9-1. ダブルクリックの入口（5つ）

| ファイル | 何をするもの |
|---|---|
| `Cynovela-start.command` | **起動する。**何も入っていない状態 |
| `Cynovela-demo.command` | **起動する。**サンプル資料が入った状態（初回に自動で読み込みます） |
| `Cynovela-stop.command` | **止める。**資料と設定は残ります |
| `Cynovela-add-folder.command` | **読み込む元のフォルダを足す。**起動はしません |
| `check-managed-mac.command` | **この Mac で動かせるかを調べる。**測るだけで、設定は変えません |

**ダブルクリックでは、番号の指定などの細かい指定ができません。** それらはターミナルから
指定します。

### 9-2. ターミナルの指定（主なもの）

| 指定 | 何をするもの |
|---|---|
| `./launch.sh` | 起動する（何も入っていない状態） |
| `./launch.sh --demo` | 起動する（サンプル資料あり） |
| `./launch.sh --port 9000` | 使う番号を決める（指定しなければ自動で選ばれます） |
| `./launch.sh --local-only` | この Mac の中からだけ開けるようにする |
| `./launch.sh --add` | 読み込む元のフォルダを足す |
| `./launch.sh --list` | 足してあるフォルダを見る |
| `./launch.sh --check` | 起動せず、動く条件だけを調べる |
| `./launch.sh --setup` | 足りないものを用意し直す |
| `bash stop.sh` | 止める |

全部の指定は `./launch.sh --help-all` で見られます。

## 10. 用語集

はじめて見る言葉が出てきたら、ここを見てください。

| 言葉 | 意味 |
|---|---|
| **RAG** | 自分の資料の中から関係のある部分を探し出し、それをもとに答えを作るやり方。モデルが元から知っていることではなく、渡した資料に基づいて答えます |
| **読み込み元（Source）** | 資料が入っているフォルダの場所。ここを登録することから始まります |
| **取り込み** | 読み込み元のファイルを実際に開いて、中の文章を取り出すこと |
| **チャンク** | 取り出した文章を、検索しやすい長さに切り分けた一片。既定は512文字ずつ、64文字ぶん重ねて切ります。**取り込みにかかる時間は、ファイルの数ではなくこの数で決まります** |
| **ワークスペース** | 資料をまとめておく入れ物。誰が見られるかをここで分けます |
| **コレクション（Collection）** | ワークスペースと読み込み元を結び付けたもの。「どの資料をどの入れ物に入れるか」の対応です |
| **公開** | 取り込んだ資料を、質問の対象になる状態にすること。ここで個人情報を伏せる処理が走ります。**公開しないと質問に使われません** |
| **伏字** | 氏名・電話番号・住所・マイナンバーなどを隠して表示すること。誰で入ったかによって、そのまま見えるか隠れるかが変わります |
| **プロバイダー** | 答えを作るモデルのつなぎ先。LM Studio・Ollama・OpenAI と同じ形の口を持つサービスから選びます |
| **モデル** | 答えの文章を作る側の中身。プロバイダーが持っているものから1つ選びます |
| **埋め込み（Embedding）** | 文章を数字の並びに変換して、意味の近さで探せるようにする処理。同梱の AIモデルがこれを行います |
| **再ランク（Rerank）** | 探し出した候補を、質問との関係が強い順に並べ直す処理 |
| **出典** | 答えの根拠になった資料の場所。答えと一緒に表示されます |

## 11. フォルダの中身

展開したフォルダの、主なものだけを挙げます。

```
chewie/
├── QUICKSTART.md               ← この文書
├── START-HERE.md               くわしい説明（導入・再起動・作り直し・削除）
├── cynovela.yaml               設定。初回の画面を見逃したときの控えもここにあります
├── launch.sh                   起動の入口（ターミナル用）
├── stop.sh                     停止
├── Cynovela-start.command      ダブルクリックの入口（5本）
├── Cynovela-demo.command
├── Cynovela-stop.command
├── Cynovela-add-folder.command
```

## 12. うまくいかないとき

**「開けません」と出る / ダブルクリックしても何も起きない**

この Mac の設定が止めています。`check-managed-mac.command` をダブルクリックすると、
何が止めているかが出ます。

**ブラウザが開かない**

起動したターミナルの画面に出ている `開く場所` を、自分でブラウザに入れてください。
番号は 8765 とは限りません。

**パスワードがわからない**

**初回の起動のときに、ターミナルの画面へ1回だけ出ています。**見逃した場合は、展開したフォルダの `cynovela.yaml` の `auth.admin_initial_password` を見てください。

**質問しても答えが返らない / エラーになる**

5節をやり直してください。とくに **`💾 LLM 設定をまとめて適用` を押したか**を
確かめてください。つなぐ先（LM Studio など）が動いているかも確かめます。

**`📋 モデル一覧を取得` を押しても何も出ない**

つなぐ先にモデルが読み込まれていません。LM Studio などの側でモデルを読み込んでから、
もう一度押してください。

**「該当なし」しか返らない**

そのワークスペースに公開済みの資料がありません。7-5 を確かめてください。

**取り込みが終わらない**

ページ数の多い資料は時間がかかります。7-3 の表を目安にしてください。画面を閉じても
裏で動き続けます。

**画像の中の文字が検索できない**

**画像ファイルは読めません（現在開発中）。**

**もっとくわしく知りたい**

`docs/INDEX.md` に、文書の全数が読み手ごとに並べてあります。
